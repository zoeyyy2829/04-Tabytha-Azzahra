Rangkuman Materi Workshop

Tadi dijelasin klo kita jangan gampang percaya sama janji perusahaan, apalagi klo kedengerannya terlalu bagus. Harus dicari tau dlu beneran atau nggak, jangan langsung percaya aja.
Terus, klo mau ikut program kayak Studi Independen Bersertifikat, dipikirin dlu baikbaik. Jangan cuma ikut ikutan atau ngejar sertifikat, tapi malah nggak serius ngejalaninnya. Sayang juga klo udah daftar tapi ujung ujungnya nggak dimanfaatin.

Point point penting:
- Jangan gampang percaya sama janji perusahaan yang blm jelas.
- Cari tau dulu sebelum ikut program atau nerima tawaran.
- Klo udah daftar, usahain serius sampai selesai.

Pendapat tentang workshop:

Menurut saya, materi tadi cukup penting sih, soalnya kita jadi lebih hatihati klo ada tawaran program atau kerjaan yang kedengerannya bagus banget. Jangan sampe langsung percaya karena tergiur benefitnya. Mending cari tau dlu kebenarannya dan pikirin baik baik sebelum mutusin buat ikut, biar nggak nyesel nantinya.
